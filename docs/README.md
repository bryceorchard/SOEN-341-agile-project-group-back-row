# CareerConnect — Documentation

This folder holds the project's non-code deliverables. (Repository folder
structure, issue #22.)

## Layout

```
docs/
├── README.md            # this index
├── CONTRIBUTING.md      # team process: workflow, branching, PRs, review, DoR/DoD (#23)
├── ERD.md               # database entity-relationship diagram
├── minutes/             # meeting minutes (attendance, decisions, action items) (#27)
│   └── minutes-template.md
└── sprint-1/            # Sprint 1 deliverables
    ├── sprint-1-plan.md # backlog, priorities, risks, effort, capacity (#24)
    └── appendix-a.md    # Sprint 1 work-plan table (#24)

AI-log/                  # AI usage logs, one subfolder per member (repo root)
└── <Name>/
```

- **Documentation** lives in `docs/`.
- **Minutes** live in `docs/minutes/`.
- **AI logs** live in `AI-log/<Name>/` at the repo root (one PDF per member per sprint,
  plus per-interaction markdown entries).
- **Sprint deliverables** live in `docs/sprint-<n>/`.
